# Changelog

## 0.1.0 — Initial Release

- Multi-source document acquisition pipeline
- Shadow library support (Sci-Hub, Anna's Archive, LibGen, Z-Library)
- CLI with 14 commands: version, init, examples, add, import, run, status, list, show, retry, search, serve, gui, sources
- Tkinter GUI
- HTTP acquisition server (FastAPI)
- Per-document timeout, error taxonomy, transient/permanent failure tracking
- Playwright browser fallback for JS-gated pages
